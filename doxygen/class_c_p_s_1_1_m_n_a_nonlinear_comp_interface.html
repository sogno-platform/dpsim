Detailed Description

Opt-in converged Newton coupling for variable-matrix EMT components. Pre-step prepares the first tangent stamp. A check computes trial states and true residuals without committing them. If any component fails its check, every nonlinear component prepares a new tangent at that trial. Post-step commits only after all checks pass. Histories of other components remain fixed throughout the network iteration.
