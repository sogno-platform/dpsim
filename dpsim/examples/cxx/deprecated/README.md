# Deprecated C++ examples

These examples are retained for historical reference and are no longer added to
the DPsim example build:

- `DAE/`: the standalone DAE test
- `signals/`: FIR filter and turbine governor demos
- `timer/`: timer demo

Their CMake files are preserved with the examples but are not included by the
active CMake configuration. They may require adaptation before they can be
built with current DPsim.
